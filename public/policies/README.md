# Policy documents

Upload Honeytots School policy PDFs here.

- Files should follow the naming pattern: `<slug>-v<version>.pdf`, e.g. `safeguarding-child-protection-v1.0.pdf`
- After upload, register each file in `src/content/site-cms.ts` by setting `policyEntries[i].file` to the
  site-relative path (e.g. `/policies/safeguarding-child-protection-v1.0.pdf`) and flipping
  `lastConfirmedBySchool` to `true` once the school has signed off in writing.
- Do not upload draft or unreviewed documents without written confirmation from Honeytots leadership.
